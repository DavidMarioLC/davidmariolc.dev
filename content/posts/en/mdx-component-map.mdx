## The map

Velite compiles MDX to a function body. Rendering it means handing that function
a map of the components a body is allowed to use.

## Why it is a contract

An unregistered component is not a missing style, it is a build error that names
the post and the component. That is the whole point.

## What it cannot catch

The map validates names, not props. A `<Callout type="danger" />` with no such
variant still renders — types catch that, the map does not.
